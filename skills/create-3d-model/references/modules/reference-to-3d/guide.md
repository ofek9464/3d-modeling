# Reference reconstruction router

Inspect and classify the supplied material. Establish the shared source and coordinate contract before exact reconstruction. Reuse an agreed canonical policy; resolve measured contradictions rather than treating the front view as universally authoritative.

Choose the smallest method:
- [Wireframe extraction](../wireframe-to-3d/guide.md) for line art; its helper produces contour evidence, not a solved volume.
- [Contour meshes](../contour-to-mesh/guide.md) for exact filled silhouettes.
- [Segmentation](../source-part-segmentation/guide.md) for touching or overlapping structural parts.
- [Orthographic registration](../orthographic-registration/guide.md) for multiple views, then [constraint checks](../multiview-constraint-solver/guide.md) only for conflicts.
- [Mascot reconstruction](../mascot-logo-reconstruction/guide.md) for a complete exact logo or mascot.
- [Mesh modeling](../blender-modeling/guide.md) for geometric interpretation or depth not supplied by the source.

Use [reference validation](../reference-analysis-validator/guide.md) when claiming exact fit. Apply texture or look modules only when the output requires them. Read [reference examples](recipes.md) for analyzer and Blender patterns, and [reconstruction reference](references/overview.md) for deeper source analysis.

Completion means the requested reconstruction is delivered with evidence for the supported views and explicit assumptions for unseen geometry. A front-projected visual skin must be labeled as such.
