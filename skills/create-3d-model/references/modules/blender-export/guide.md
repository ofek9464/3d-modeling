# Blender export

Use the requested format, runtime, scale, and asset budget from the shared contract. When none is named for a new portable model, default to GLB plus a versioned Blender source. Render-only or existing-source edits do not require unrelated exports.

Choose only in-scope objects. Preserve the source and export a copy when applying transforms, modifiers, reduction, baking, or animation conversion. Optimize only to meet an actual target requirement. No universal 15 MB cap, texture resolution, triangle limit, or prohibition on rigs applies.

Read [format recipes](recipes.md) for GLB, FBX, OBJ, STL or USD settings, and [export reference](references/overview.md) for round-trip issues or batch export. Legacy lightweight-web examples apply only when that profile is selected.

Verify the output exists and re-import or inspect it in a target-compatible viewer when practical. Check relevant geometry, units, axes, materials, images and animation. For printing, verify printable geometry and distinguish digital checks from physical fit.

Completion means the requested file is delivered with target checks and any unsupported effects or unverified behavior stated.
