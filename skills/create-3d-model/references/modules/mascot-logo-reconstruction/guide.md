# Exact mascot or logo reconstruction

Use this for a requested source-faithful designed symbol. Establish the shared source contract, visible structural parts, important features, depth assumptions, output target and acceptance tolerances.

Use reference-analysis-validator for source evidence. Add source-part-segmentation only for touching or overlapping parts, contour-to-mesh for measured silhouettes, and orthographic-registration for required multiple views. Use constraint-solver only when sources conflict. Reuse the selected coordinate and canonical-view policy.

Respect designed asymmetry and part counts; do not invent radial duplicates or unseen structural parts. Add depth with explicit assumptions where the sources do not constrain it. Apply atlas and surface-coverage guidance when those surfaces require textures.

Validate shape and important features before final look or animation claims. Use the relevant export and animation guides only for requested outputs. Aura, guide lines and background remain separate unless part of the requested model.

Create only the source manifest and reports needed to support the actual reconstruction claim. A quality gate means verify or repair locally, not ask the user to approve every phase. Completion means the requested asset is delivered with evidence for the required views and any inferred geometry stated.
