# Blender modeling

Use the existing coordinate, scale and source contract. Choose primitives, contours, curves, bmesh or modifiers for the requested geometry and topology. Exact source contours and part inventories constrain reconstruction when required; freeform work need not enter that pipeline.

Inspect existing geometry and preserve unrelated data. Name new objects clearly, use task-scoped collections, and establish primary dimensions and silhouette before detail. Make physical joins, clearances and solid unions according to the intended use; visual overlap recipes do not establish printability.

Read [geometry recipes](recipes.md) when a primitive, curve, modifier or mesh operation is needed. Read [advanced modeling](references/overview.md) for bmesh, topology or performance details. Check API compatibility before running examples.

Verify affected dimensions, topology, normals and connections. Inspect relevant views when shape changes. Completion means the requested geometry and applicable structural and visual checks are complete.
