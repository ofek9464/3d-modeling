# Blender lighting

Inspect the current lights, world, material response and requested look before changing them. Work on in-scope lighting and preserve unrelated settings. Place and aim lights using the actual subject bounds and scale.

Choose lighting appropriate to the source: studio, outdoor, practical emitter, stylized scene, or a measured reference. Light energy, ratios, color temperature and emitter size in examples are starting values, not mandatory presets.

Read [lighting recipes](recipes.md) for a selected setup and [advanced lighting](references/overview.md) for HDRI, volumetrics, groups or linking. Use a network asset only within existing authorization. Use [look calibration](../reference-look-calibration/guide.md) when reference appearance must be matched.

Inspect a proof render under the same camera and material conditions before and after the correction. Completion means lighting meets the requested appearance without hiding geometry or UV errors.
